Script or AI?

An interrogator model questions a hidden counterpart and says, round by round, how likely it is to be an AI. The counterpart is a plain script or a model told to act like one.

Models: muse-spark-1.3 through the Meta Model API, for both the interrogator and the impersonator.

What the interrogator believes

Each dot is one game's final suspicion; the vertical line is the mean. Samples are small (10 to 30 games per opponent), so read gaps as hints unless the written summary says otherwise. Raw logs and written summaries are in the results folder of the repo.
